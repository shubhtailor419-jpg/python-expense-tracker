# Python Expense Tracker

A simple command-line Expense Tracker built with Python that helps users record, manage, and monitor their daily expenses. The application provides an easy-to-use menu-driven interface for adding, viewing, summarizing, and deleting expenses.

## Features

* Add new expenses with description and amount
* View all recorded expenses
* Display expense summary with total expenses and total amount spent
* Delete unwanted expense records
* Input validation for better user experience
* Simple command-line interface

## Technologies Used

* Python 3

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/python-expense-tracker.git
```

2. Navigate to the project folder:

```bash
cd python-expense-tracker
```

3. Run the application:

```bash
python expense_tracker.py
```

## Usage

When you start the program, the following menu will be displayed:

```text
==============================
EXPENSE TRACKER
==============================
1. Add Expense
2. View Expenses
3. View Summary
4. Delete Expense
5. Exit
==============================
```

Choose an option by entering the corresponding number.

## Example

```text
Enter choice (1-5): 1
Enter description: Grocery Shopping
Enter amount: 1200

Expense added successfully.
```
